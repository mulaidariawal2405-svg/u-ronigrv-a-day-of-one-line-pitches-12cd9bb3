# A Day of One-Line Pitches

Entry for the make.fun bounty `u-ronigrv-a-day-of-one-line-pitches-12cd9bb3`.

`main.py` prints exactly one sentence (under 240 characters) meant to convince
a friend who has never coded to let an AI agent build their first app idea on
make.fun. Pure Python standard library, no dependencies.

Run it:

```sh
python3 main.py
```
